# See what your meal needs—and find the next update

A saved photo without a nutrition estimate now says “No estimate yet” instead of promising a question that does not exist. Preview installations can also discover the matching stable release and newer versions.

- “A question about your meal” appears only when a question is actually open.
- Failed processing still offers a retry, while records without an estimate remain available to open and discuss.
- Update checks understand preview version names and continue to offer stable releases only.

## Installation and validation

If an older preview incorrectly says it is up to date, download this release’s APK and install it over the existing app. Do not uninstall first; the existing preview cannot receive this checker fix until it has been updated.

The short-dialog layout correction from 1.2.12 is retained. Automated checks cover preview-to-stable version selection and the diary’s distinction between missing estimates, questions and failures. Android validation and CI results are recorded in the pull request.
