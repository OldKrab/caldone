# Your next CalDone update is easier to find

CalDone now lets you know when a new release is ready, with the choice to download and install when it suits you.

- See what changed and start future updates directly from Settings.
- Add meals to the journal day you selected, including past days.
- Keep the Assistant message field and Send button above the keyboard.

## Installing this release

Install the attached ARM64 APK to get in-app updates for future releases. Automatic checks run when CalDone opens or returns to the foreground, at most once every eight hours. Downloads require your tap, and Android asks you to confirm installation.

## Other improvements

- Routine actions respect a denied notification permission.
- Meal-confirmation search diagnostics retain their context.
- Research-stream diagnostics and retry requirements are preserved.

## Validation and known limitations

Source checks, 194 automated tests, native update-policy tests, and an ARM64 release build passed during development. An actual same-signer upgrade with local data and the Android permission/installer flows remain unverified on a device.

The existing signing certificate is retained for compatibility. It uses the public React Native template key, so it does not establish exclusive publisher identity. The updater restricts downloads to the official GitHub repository and verifies the release digest and APK compatibility.
