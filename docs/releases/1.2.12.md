# Keep meal answers and corrections in one conversation

Answer a portion question, add another dish, or ask for a correction—CalDone now keeps the meal’s context together so you can continue without starting over.

- Answer only what you know, including “Not sure”; unrelated questions stay open and accepted answers leave the form immediately.
- Follow one current processing step across chat and meal screens, including web search and recognition retries. Your original note stays in your own words.
- Refresh the Codex model list to choose the models available to your account, including Astra when offered.

## Changes and validation

Meal capture, clarification forms, dish additions and chat now use a persistent agent conversation. Nutrition edits, question resolutions and Undo receipts commit together; interrupted requests retain their input for recovery without duplicating saved edits. Search history remains visible after reopening chat, and a failed screen refresh cannot turn a completed nutrition edit into a failed operation.

This release also includes the manual editor title, explicit Undo state, meal action placement and background dish addition improvements merged since 1.2.11. Existing sign-in diagnostics, notification permission choices and journal-date behavior are preserved.

The Android foreground notification now describes an active request and ends when processing finishes. Notes already overwritten by an older build cannot be reconstructed automatically.

Validated with automated agent, repository and UI interaction tests, TypeScript checks, live Astra requests, native component checks and a preview APK installation/startup check. Component checks and live provider checks were performed separately; a complete authenticated AI session on a physical Android device remains unverified.
