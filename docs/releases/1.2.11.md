# Clearer Assistant errors, with details when you need them

When an AI request returns an error page, CalDone now shows a readable message and lets you inspect the technical details separately.

- Open Show details to read and copy the available error information.
- Retry a failed chat request while keeping changes already saved.
- Read short dialog messages in full, including update-check results.

## Technical details

Provider HTML and SVG errors are summarized in English or Russian across chat, selected-meal, and failed-tool errors, including saved failures. Details appear as selectable plain text, with recognized credential fields redacted from display and copying. An error page containing a transport-error phrase no longer triggers an automatic transport retry.

This improves error presentation; it does not resolve the underlying provider-access failure. The app retains error strings and does not infer HTTP status from page content.

## Validation and known limitations

TypeScript and automated tests passed for the included fixes, and the Assistant change passed an Android JavaScript/Hermes export. Native text selection, copying, enlarged-font layout, and an actual upgrade with local data remain unverified on a device.
